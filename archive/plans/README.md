# plans/ — планы квартир (изображение для экрана плана)

Экран плана открывается между списком и видами из окна. Файлы называются
по полному коду квартиры:

    plans/<код>.jpg      напр. plans/2-02-205.jpg

Пока у квартиры нет своего файла — показывается демо-план
(`../plan-placeholder.jpg`) с плашкой «Демо-план».

Как добавить реальные планы:
1. Положить `plans/<код>.jpg` (код в полном формате, как в CSV/приложении,
   напр. `1-02-201`, а не `1-02-01`).
2. Пересобрать данные:  `python tools/build_data.py --use-views`
3. Запушить.

`build_data.py` сам подставит реальный путь для квартир, у которых файл
есть, остальным оставит плейсхолдер.
