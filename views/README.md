# views/ — реальные рендеры видов из окна

Файлы называются по конвенции:

    <код_квартиры>_<индекс_камеры>.jpg      напр. 2-02-205_0.jpg

Пока у камеры нет своего файла — сайт показывает демо-панораму
(`../panorama.jpg`). Для камер с реальным файлом автоматически:
начальный ракурс = 0/0, применяются ограничения углов из таблицы
(относительно перпендикуляра к окну) — никакого кода писать не нужно.

## Как добавить рендеры (просто)

1. Отрендерить 360 в UE. Структура папок как обычно:

       360/<корпус>-<этаж>-<кв>/<timestamp>/<...>.ViewCameraComponent<юнит>_<idx>.png

2. Запустить импортёр — он сам определит код квартиры и индекс камеры,
   сожмёт (4096×2048, JPEG q85) и разложит в `views/`, затем пересоберёт
   `data/apartments.json`:

       python tools/import_views.py "E:/UE_Projects/Marta/Vesper/Vesper/360"

   (без аргумента берётся путь по умолчанию из скрипта; `--dry-run` —
   показать план без записи; `--width/--quality` — другое качество.)

3. Запушить:

       git add -A && git commit -m "views <коды>" && git push

Корпус берётся из имени папки (`2-02-05` → корпус 2), потому что имя
компонента содержит только юнит, а юниты повторяются между корпусами.

## Ручной путь (без импортёра)

Положить файлы `views/<код>_<idx>.jpg` самому и выполнить:

    python tools/build_data.py --use-views

Скрипт пропишет реальные пути к существующим файлам, для отсутствующих
оставит демо-панораму.
