# views/ — реальные рендеры видов из окна

Пока здесь пусто и сайт показывает демо-панораму (`../panorama.jpg`) для всех камер.

Когда появятся реальные 360-рендеры, положите сюда файлы по конвенции:

    <код_квартиры>_<индекс_камеры>.jpg

Например для квартиры `1-02-201` с камерами _0, _1, _2:

    views/1-02-201_0.jpg
    views/1-02-201_1.jpg
    views/1-02-201_2.jpg

Индексы камер (_0/_1/...) берутся из суффикса Component в
`data/apartment_view_cameras.csv`.

Затем перегенерируйте данные с флагом:

    python tools/build_data.py --use-views

Скрипт пропишет реальные пути к существующим файлам, а для отсутствующих
оставит демо-панораму как фолбэк.
