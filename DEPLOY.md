# Деплой и обновление данных (свой сервер)

Сайт статический (HTML/JS/картинки) + периодическое обновление данных о
квартирах из XML-фида по расписанию (cron). Данные хранятся на сервере,
фид дёргается ~4 раза в сутки — не при каждой загрузке страницы.

## 1. Выложить файлы

Скопировать содержимое репозитория в корень сайта (docroot), например
`/var/www/vesper360/`. Ключевое:

    index.html
    panorama.jpg
    views/                     реальные виды (<код>_<idx>.jpg)
    data/
      apartment_view_cameras.csv   статичные камеры (не меняется)
      feed_snapshot.xml            последний удачно скачанный фид (кеш)
      apartments.json              то, что реально читает сайт
    tools/build_data.py            сборщик данных (запускается по cron)

Сайт читает `data/apartments.json` со своего же домена — **CORS не нужен**.

## 2. Обновление данных по расписанию (cron)

Команда (обновить данные из живого фида):

    cd /var/www/vesper360 && /usr/bin/python3 tools/build_data.py --fetch --use-views

Что делает:
1. `--fetch` — качает фид с `FEED_URL` (задан в `tools/build_data.py`).
   - Успех → атомарно перезаписывает `data/feed_snapshot.xml` (это же кеш).
   - Ошибка сети/фида → снимок НЕ трогается, сборка идёт из прошлого →
     сайт не ломается.
2. Парсит фид + камеры из CSV, пишет `data/apartments.json`.
3. `--use-views` — для камер с файлом в `views/` ставит реальный путь,
   иначе демо-панораму.

Расписание 4 раза в сутки (каждые 6 часов):

    0 */6 * * *  cd /var/www/vesper360 && /usr/bin/python3 tools/build_data.py --fetch --use-views >> /var/log/vesper360-sync.log 2>&1

В **ISPmanager**: раздел «Планировщик задач (cron)» → добавить задание с
этой командой и временем «каждые 6 часов». Путь к python уточнить через
`which python3`.

## 3. Требования

- **Python 3.6+**. Для cron-обновления данных внешние пакеты НЕ нужны
  (только стандартная библиотека). Node.js/PHP на сервере есть, но для
  этой задачи не требуются.
- Пакет **Pillow** нужен только для импорта/сжатия картинок
  (`tools/import_views.py`), а это ручной шаг при добавлении новых
  рендеров, не cron. Ставится: `pip3 install pillow`.

## 4. Добавление новых видов (когда отрендерят квартиру)

Разово, руками (не cron):

    python3 tools/import_views.py /path/к/папке/с/рендерами
    # затем выложить обновлённые views/ и data/apartments.json на сервер

Подробности — в [views/README.md](views/README.md).

## 5. Периодичность

Сейчас 4×/сутки (каждые 6 ч) — как просил клиент. Если понадобится чаще
или реже, поменять только cron-расписание; в коде ничего не трогать.
